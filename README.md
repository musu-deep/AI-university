# AIGEN University

نموذج تفاعلي أولي لجامعة متعددة التخصصات تُصمَّم منظومتها الأكاديمية والتشغيلية وتُدار بواسطة الذكاء الاصطناعي، من إعداد المناهج وتقديم المقررات إلى الإشراف البحثي والتقييم. صُمم النموذج لمراجعة الفكرة ومسارات العمل قبل اختيار التقنية والمزود ومسار الترخيص والاعتماد.

تحتفظ الجامعة باسمها وهويتها المستقلة، وتُذكر صلتها المؤسسية في التذييل: **إحدى الأذرع الأكاديمية لـ FAS Development**.

تتضمن الواجهة صورة رئيسية لبيئة الجامعة الرقمية، ومشهدًا للطلاب عند كشك الخدمة الذاتية للتسجيل والتحضير وتسليم الأعمال.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. لا يحتاج النموذج إلى تثبيت حزم أو إعداد مفاتيح وصول.

## ما يمكن استكشافه

- لوحة الجامعة ومؤشرات التعلم والجودة.
- رحلة الطالب وملف الكفايات وأدلة الإتقان.
- البرامج والمسارات والمقررات.
- القبول والتسجيل، مع إضافة طلبات تجريبية.
- سجل الوكلاء وتخصصاتهم ونطاق صلاحياتهم وحالة معايرتهم.
- إشراف الدراسات العليا، ومراحل مراجعة البحوث، وتشكيل لجان المناقشة.
- التقويم، والاعتراضات، والمختبرات التطبيقية، وسجل الحوكمة.
- تصدير بيانات العرض بصيغة JSON وإعادة ضبط بيانات المحاكاة.

## حدود النسخة

هذه واجهة تصورية ببيانات افتراضية تحفظ محليًا عبر `localStorage`. لا يوجد اتصال فعلي بنماذج ذكاء اصطناعي، أو نظام قبول، أو قاعدة بيانات، أو جهة اعتماد. أسماء البرامج والأشخاص والمؤشرات لأغراض العرض فقط، ولا تمثل مؤهلات معتمدة.

## أساس التصميم

يفصل النموذج بين أدوار التدريس والإرشاد والإشراف والتقييم ومراجعة الاعتراضات، ويوثق إصدار النموذج ونطاقه، ويعرض مسارات القرار والمراجعة المستقلة. هذه فرضيات تشغيلية تحتاج إلى اختبار ومراجعة نظامية وأكاديمية.
